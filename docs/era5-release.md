Daily weather over France (41 to 51.5° N, 5.5° W to 10° E) from ERA5, read from Open-Meteo's public bucket: one Parquet asset per year, one row per 0.25° grid point and UTC day, with the nine daily variables of Panache's weather model. Columns, rules and sources are described in the [README](https://github.com/AdrienJKTH/panache-archive#readme).

Assets are added by the `ERA5` workflow as they are built.

Contains modified Copernicus Climate Change Service information [2026].
