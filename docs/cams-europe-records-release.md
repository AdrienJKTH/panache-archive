Each cell's record of the CAMS European air quality reanalyses over the whole CAMS Europe domain (30 to 72° N, 25° W to 45° E): one `.cells` asset per variable and grid, holding the variable's consecutive validated years, one 0.1° cell per frame, so that a cell's years are read in two small HTTP requests (Panache's D134). Two grids: 2013-2019, centred on x.x0° (until 2017 the reanalysis stops at 70° N: the northern rows are null), and 2020 onwards, centred on x.x5°. The values are the very hundredths of the yearly assets of [cams-europe-v1](https://github.com/AdrienJKTH/panache-archive/releases/tag/cams-europe-v1), which each record names in its metadata. The format is described in the [README](https://github.com/AdrienJKTH/panache-archive#the-whole-domain).

Assets are added by the `Records` workflow, which builds only what the release lacks: run it again when the archive gains a validated year.
